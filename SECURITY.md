# Security Policy

## Reporting a vulnerability

Please do not publish suspected vulnerabilities in a public issue. Use the repository's private GitHub security advisory feature so the problem can be investigated before disclosure.

Do not include live API keys, bot tokens, database passwords, Telegram session strings, or personal user data in a report. Revoke and rotate a credential immediately if you believe it has been exposed.

## Supported version

Security fixes are applied to the latest version on the default branch.
